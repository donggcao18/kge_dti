INTRODUCTION

Introduction: Mathematical Formulation & Challenges

DTI Prediction Formulation

Given drug set \(\mathcal{D} = \{d_1, \dots, d_m\}\) and target set \(\mathcal{T} = \{t_1, \dots, t_n\}\), given the interaction matrix: \(Y \in \{0, 1\}^{m \times n}\)

Objective: Learn a mapping function \(f: \mathcal{D} \times \mathcal{T} \rightarrow [0, 1]\) to estimate:

$$\hat{y}_{ij} = P(y_{ij} = 1 \mid d_i, t_j)$$

Core Challenges

  • Extreme Sparsity: Matrix density \(\rho = \frac{|Y^+|}{m \times n} \approx 0.65\%\).
  • Incomplete Supervision: Unobserved pairs \(y_{ij} = 0 \neq\) confirmed negatives.
  • Heterogeneity: Fusing multi-scale context \((z_d, z_p)\) with structural descriptors \((s_d, s_p)\).

BACKGROUND AND RELATED WORK

Existing DTI Prediction Approaches

Methodology Taxonomy

1. Descriptor-based Methods: Uses intrinsic molecular/sequence features.

$$\hat{y}_{dp} = F(s_d, s_p)$$

Pros & Cons: Captures chemical properties, but ignores global network topology.

2. Network & KG-based Methods: Explores network topology via KG Embeddings.

$$z_e = \text{KGE}(e, G), \quad \hat{y}_{dp} = F(z_d, z_p)$$

Pros & Cons: Captures multi-scale relations, but suffers from data sparsity.

3. Our Proposal (KGE-NFM): Fuses relational graph context and structural descriptors.

$$\hat{y}_{dp} = \text{NFM}(z_d, z_p, s_d, s_p)$$

Synergy: Combines topology and molecular features via high-order non-linear interactions.

Biomedical Knowledge Graph Representation

Graph Definition & Structure

Knowledge Graph \(\mathcal{G} = (\mathcal{E}, \mathcal{R}, \mathcal{T})\) with factual statement triples: \((h, r, t) \in \mathcal{T}\) where \(h, t \in \mathcal{E}\), \(r \in \mathcal{R}\).

Knowledge Graph Embedding (KGE)

Maps discrete entities/relations into continuous space \(\mathbb{R}^d\) using a scoring function to maximize observed triple plausibility: \(f(h, r, t) \in \mathbb{R}\).

Triple Scoring & Negative Sampling

Negative instances \(\mathcal{T}^-\) generated via corruption: \((h, r, t) \rightarrow (h', r, t) \lor (h, r, t')\). Learned via margin-based ranking loss:

$$\mathcal{L}_{KGE} = \sum_{(h,r,t) \in \mathcal{T}^+} \sum_{(h',r,t') \in \mathcal{T}^-} \max\left(0, \gamma + f(h', r, t') - f(h, r, t)\right)$$

Role in DTI Prediction

Compresses multi-scale topological graph context into dense static vectors for downstream learning:

$$\mathbf{z}_e = \text{KGE}(e \mid \mathcal{G}), \quad \mathbf{z}_e \in \mathbb{R}^{d_g}$$
Graph Convolutional Networks: Undirected Graphs

Standard GCN Mechanism

Updates node representations by iteratively aggregating normalized features from local graph neighborhoods.

The Update Rule

$$H^{(k+1)} = \sigma\left( \hat{A} H^{(k)} W^{(k)} \right), \quad H^{(0)} = X \quad (2.9)$$
  • \(\hat{A} = \tilde{D}^{-1/2} (A + I) \tilde{D}^{-1/2}\): Normalized adjacency matrix (with self-connections).
  • \(W^{(k)}\): Layer-specific learnable weight matrix.
  • \(\sigma\): Non-linear activation (e.g., ReLU).

Key Insight

Stacking \(L\) layers enables each node to capture and integrate topological information from multi-hop neighborhoods.

Graph Convolutional Networks: Multi-Relational Graphs

The Challenge of Relational Data

Biomedical Knowledge Graphs assign specific types and semantic directions to edges. Standard GCNs cannot distinguish between these unique relational contexts.

Multi-Relational Update Rule

$$h_v^{k+1} = \sigma \left( \sum_{(u,r) \in \mathcal{N}(v)} c_{v,r}^{-1} W_r^k h_u^k \right) \quad (2.10)$$

Critical Limitation: \(W_r^k\) relies on relation-specific transformations. The parameter count grows linearly with the number of relations, leading to catastrophic overfitting on large vocabularies.

Advanced Scaling Architectures

Directed-GCN: Introduces inverse edges and direction-aware parameter sharing.

R-GCN: Utilizes basis or block-diagonal decomposition to parameterize relation weights.

CompGCN (Motivation): Leverages joint entity-relation composition to scale efficiently across massive relation sets (detailed in Methodology).

METHODOLOGY

Framework Overview

STAGE 1: KNOWLEDGE GRAPH EMBEDDINGS

Input multi-relational graph \(\mathcal{G}\). Encoder generates dense knowledge graph embeddings:

$$\mathbf{X}_{KGE} \in \mathbb{R}^{|E| \times d_g}$$

FEATURE FUSION

Concatenate learned KGE embeddings with static physicochemical features to generate the aggregate input vector:

$$\mathbf{x}_{input} \in \mathbb{R}^{d_{total}}$$

STAGE 2: NEURAL FACTORIZATION MACHINE

Model pairwise features and cross-field interactions \(v_i \odot v_j\) via deep neural networks, outputting the final predicted probability:

$$\hat{y}_{ij} \in [0, 1]$$

Figure 4.1: KGE-NFM framework with alternative DistMult and CompGCN encoders

DistMult Encoder

Entity & Relation Representations

Assigns a \(k\)-dimensional continuous vector to each individual entity and relation via direct embedding matrix lookup: \(\mathbf{h}, \mathbf{r}, \mathbf{t} \in \mathbb{R}^k\).

No explicit multi-hop neighborhood structural aggregation is performed at this level.

DistMult Scoring Function

Measures triple plausibility utilizing a highly efficient diagonal bilinear interaction framework:

$$f_{DM}(h, r, t) = \mathbf{h}^\top \text{diag}(\mathbf{r})\mathbf{t} = \sum_{i=1}^{k} h_i r_i t_i$$

KGE Training Objective

Optimized via the Margin Ranking Loss by substituting \(f_{DM}\) into the core objective, leveraging Adam and negative cross-corruption sampling to enforce:

$$f_{DM}(h, r, t)_{\text{positive}} > f_{DM}(h', r, t')_{\text{negative}}$$
DistMult: Extraction & Limitations

Embedding Extraction

Retrieves relational context vectors directly from the learned entity table \(\mathbf{E}\) to feed the NFM layer:

$$\mathbf{z}_d^{DM} = \mathbf{E}[d], \quad \mathbf{z}_p^{DM} = \mathbf{E}[p]$$

Structural Limitations

  • Symmetry Constraint: Forced to treat directional biomedical relations as identical:
    $$f_{DM}(h, r, t) = f_{DM}(t, r, h)$$
  • Neighborhood Ignorance: Scores isolated triples without multi-hop structural aggregation.

Motivation for CompGCN

These flaws necessitate **CompGCN** to effectively handle asymmetric biological paths and integrate relational neighborhood evidence via message passing.

CompGCN Encoder: Augmentation & Composition

Multi-Relational Graph Augmentation

Unlike standard GCNs, CompGCN accounts for both semantic types and edge directions by enriching the graph with inverse relations and self-loops:

  • Original Relation: \((u, r, v)\)
  • Inverse Relation: \((v, r^{-1}, u)\)
  • Self-loop Relation: \((u, \top, u)\) for every entity

Entity-Relation Composition (\(\phi\))

Neighbor entity representations are composed with their connecting relation embeddings before neighborhood aggregation:

$$m_{u,r}^k = \phi(h_u^k, h_r^k) \quad (4.12)$$

Selected Operator: Element-wise multiplication (\(\odot\)), which effectively applies a relation-dependent feature gating mechanism:

$$\phi(h_u^k, h_r^k) = h_u^k \odot h_r^k \quad (4.16)$$
CompGCN Encoder: Relation-Aware Message Passing

Node Representation Update

Aggregates composed messages using direction-specific matrices \(W_{\lambda(r)}^k\) (Original, Inverse, Self-loop):

$$h_v^{k+1} = \sigma \left( \sum_{(u,r) \in N(v)} W_{\lambda(r)}^k \phi(h_u^k, h_r^k) \right) \quad (4.17)$$

Relation Update & Benefit

Relation embeddings evolve alongside entities to maintain alignment in the vector space:

$$h_r^{k+1} = W_{rel}^k h_r^k \quad (4.19)$$

Where \(W_{\lambda(r)}^k\) is selected according to edge direction, and \(\sigma\) is a nonlinear activation. The direction function is defined as: \(\lambda(r) \in \{O, I, S\} \quad (4.18)\)

Drug-Target Feature Construction

Multimodal Feature Field Set

Candidate pairs are mapped into four distinct feature fields to capture both network topology and chemical signatures:

$$F_{dp} = \{ \underbrace{z_d, z_p}_{\text{Relational Context}}, \underbrace{s_d, s_p}_{\text{Intrinsic Structure}} \} \quad (4.23)$$

Unified Pair Representation

Features are fused via concatenation (\(\parallel\)) into a hybrid vector to ensure joint relational-structural synergy:

$$\mathbf{x}_{dp} = [z_d \parallel z_p \parallel s_d \parallel s_p] \quad (4.24)$$
  • \([z_d, z_p] \in \mathbb{R}^k\): KG embeddings for global network positions.
  • \(s_d \in \mathbb{R}^{1024}\): Morgan fingerprints for local molecular structures.
  • \(s_p \in \mathbb{R}^{147}\): CTD descriptors for protein sequence properties.
Neural Factorization Machine: Interaction & Projection

Field-Based Projection

Projects input fields into a shared latent space:

$$u_m = P_m x^{(m)}_{dp} + b_m \quad (4.25)$$

Bi-Interaction Pooling

Captures pairwise non-linear interactions between relational context and structural descriptors:

$$f_{BI} = \frac{1}{2} \left[ \left( \sum_{m=1}^M u_m \right)^2 - \sum_{m=1}^M u_m^2 \right] \quad (4.26)$$
Neural Factorization Machine: Deep Prediction Layers

Deep Hidden Layers (MLP)

The interaction vector \(f_{BI}\) is processed through non-linear layers to learn high-order DTI patterns:

$$a^{(l+1)} = \text{ReLU} \left( W^{(l)} a^{(l)} + b^{(l)} \right) \quad (4.27)$$

Final DTI Prediction

Combines linear field terms with the non-linear interaction output to compute the final interaction probability \(\hat{y}_{dp} = \sigma(o_{dp}) \quad (4.29)\):

$$o_{dp} = \sum_{m=1}^M (a_m^\top x_{dp}^{(m)} + c_m) + \text{MLP}(f_{BI}) \quad (4.28)$$

Binary Classification Objective (BCO)

Optimized via Binary Cross-Entropy loss using the estimated probabilities against true interaction labels:

$$\mathcal{L}_{DTI} = -\frac{1}{N} \sum_{i=1}^N \left[ y_i \log(\hat{y}_i) + (1-y_i) \log(1-\hat{y}_i) \right] \quad (4.30)$$

EXPERIMENTAL SETUP AND RESULTS

Experimental Configuration

Benchmarks & Data Settings

  • Dataset & Ratios: Yamanishi08 DTI benchmark evaluated under 1:1 (balanced) and 1:10 (imbalanced) settings to reflect real-world interaction sparsity.
  • Evaluation Protocol: 10-fold cross-validation under a warm-start scenario (entities are observed during training but in novel test combinations).

Feature Preprocessing & Anti-Leakage

  • Protein Descriptors: 147-dimensional CTD descriptors reduced to 100 PCA components to mitigate dimensional complexity.
  • Data Leakage Prevention: PCA and scaling parameters are fitted strictly on training folds before projecting onto test folds.

Core Architecture Hyperparameters

KGE Stage (CompGCN) 200-dim embeddings, 3 message-passing layers, 5 negative samples per positive triple.
NFM Stage (Classifier) 2 hidden layers (128 units each), ReLU activation, implemented with early stopping.

Evaluation Metrics

CONCLUSION AND FUTURE WORK

Conclusion & Future Work

Conclusion

  • Framework: Developed KGE-NFM pipeline successfully integrating KG context with biochemical descriptors.
  • Performance: CompGCN-NFM achieved SOTA on 1:10 imbalanced setting: 0.9866 ROC-AUC and 0.9362 PR-AUC.
  • Synergy: Relational and structural features provide complementary data; standalone graph completion is insufficient.

Key Findings

  • KG Embeddings: Effectively summarize global relational evidence (pathways, diseases, functions) for entities.
  • NFM Expressiveness: Successfully captures high-order nonlinear interactions between heterogeneous feature fields.

Future Work

  • Cold-Start Evaluation: Testing generalization on entirely unseen drugs/proteins.
  • Representation Enrichment: Integrating molecular GNNs and Protein Language Models (PLMs).
  • Encoder Expansion: Comparing ComplEx, RotatE, and TransE under the same protocol.
