\section{Conclusion}

This project presents a machine learning pipeline for drug-target interaction
prediction using knowledge graph embeddings and neural factorization machines.
The pipeline learns biomedical entity embeddings from knowledge graph triples
and combines them with drug and protein descriptor features for supervised
interaction prediction.

\section{Future Work}

Possible future directions include:

\begin{itemize}
    \item evaluate additional KGE models such as TransE, ComplEx, and RotatE;
    \item improve cold-start performance for unseen drugs and unseen proteins;
    \item integrate molecular graph neural networks for drug representation;
    \item integrate protein language models or sequence encoders;
    \item perform more systematic hyperparameter search;
    \item validate high-confidence predicted interactions using external
    biomedical databases or literature.
\end{itemize}
